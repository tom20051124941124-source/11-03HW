微分方程筆記

03 二階常係數齊次方程

把微分方程變成一個一般的二次方程，再依判別式決定解的形式。

這頁要會什麼

  • 寫出特徵方程
  • 依判別式判斷是哪一種情況
  • 寫出通解，並代回驗算

觀念

方程的形式是 y'' + a y' + b y = 0，a 和 b 是常數。

試著令 y = erx 代入。因為 erx 不會等於 0，剩下的就是特徵方程，characteristic equation：

r² + a r + b = 0

判別式根通解
大於 0兩個相異實根 r₁、r₂C₁ er₁x + C₂ er₂x
等於 0重根 rC₁ erx + C₂ x erx
小於 0共軛複根 α ± βiC₁ eαx cos βx + C₂ eαx sin βx

解題步驟

  1. 寫出特徵方程 r² + a r + b = 0。
  2. 解出 r。
  3. 看判別式，確定屬於上表哪一列。
  4. 照那一列寫出通解。
  5. 有兩個初始條件時，代入解出 C₁ 和 C₂。
  6. 代回原方程驗算。

例題

例一 y'' − 3y' + 2y = 0

r² − 3r + 2 = 0 分解成 r − 1 乘 r − 2，所以 r = 1 或 2 y = C₁ ex + C₂ e2x

驗算：ex 的二階導、一階導、本身都是 ex，係數是 1 − 3 + 2 = 0。e2x 的係數是 4 − 6 + 2 = 0。兩個都成立，線性組合也成立。

例二 y'' − 4y' + 4y = 0

r² − 4r + 4 = 0 r = 2 是重根 y = C₁ e2x + C₂ x e2x

驗算 x e2x：y' = e2x + 2x e2x，y'' = 4e2x + 4x e2x。代入後 e2x 的項是 4 − 4 = 0，x e2x 的項是 4 − 8 + 4 = 0。成立。

例三 y'' + 2y' + 5y = 0

r² + 2r + 5 = 0 判別式是 4 − 20 = −16，所以 r = −1 ± 2i y = C₁ e−x cos 2x + C₂ e−x sin 2x

驗算 e−x cos 2x：代入後 cos 項的係數是 −3 − 2 + 5 = 0，sin 項的係數是 4 − 4 = 0。成立。sin 那一項用同樣方式檢查。

考點

  • 三種判別式對應三種通解，要能默寫。
  • 重根的第二個解要多乘一個 x。
  • 複根只取 α 和 β，不需要同時寫出共軛的兩個根。

容易錯的地方

  • 重根時忘了乘 x，結果只剩一個解，通解少了一半。
  • 複根的情況漏掉 eαx 這個因子。
  • 判別式算錯，整題的形式就跟著錯。
