微分方程筆記

01 可分離變數

能把 x 和 y 分到等號兩邊的方程，兩邊各積分一次就解完了。

這頁要會什麼

  • 看出一個方程能不能分離變數
  • 照步驟解出通解
  • 用初始條件求出常數 C
  • 把答案代回原方程驗算

觀念

如果方程可以寫成 y' = g · h，其中 g 只含 x，h 只含 y，就是可分離的。

這時把 y' 改寫成 dy/dx，整理成 dy/h = g dx，兩邊再各自積分。

解題步驟

  1. 把 y' 寫成 dy/dx。
  2. 含 y 的項連同 dy 移到左邊，含 x 的項連同 dx 移到右邊。
  3. 兩邊各自積分，常數 C 只加在一邊。
  4. 解得出 y 就寫成 y = ...，解不出來就留著隱函數。
  5. 回頭看剛才除掉了什麼。被除掉的項如果本身是解，要確認有沒有漏掉。
  6. 有初始條件就代入求 C，最後代回原方程驗算。

例題

例一 y' = 2xy，而且 x = 0 時 y = 3

dy/y = 2x dx ln|y| = x² + C₁ y = C ex² 其中 C = ±eC₁

第一步除以了 y，所以 y = 0 被漏掉。不過 y = 0 本身是解，而且正好是 C = 0 的情況，通解已經包含它。

代入 x = 0、y = 3，得到 3 = C · e⁰，所以 C = 3。特解是 y = 3ex²。

驗算：y' = 6x ex²，而 2xy = 2x · 3ex² = 6x ex²，兩邊相等。初始條件 x = 0 時 y = 3e⁰ = 3，也成立。

例二 y' = x/y

y dy = x dx y²/2 = x²/2 + C₁ y² = x² + C 其中 C = 2C₁

這題解不太需要硬寫成 y = ± 根號，留成隱函數就可以。

驗算：兩邊對 x 微分，得 2y · y' = 2x，所以 y' = x/y，和原方程一致。要注意原方程只在 y ≠ 0 時有意義。

考點

  • 先判斷能不能分離，不能分離就不要硬做。
  • 常數 C 只加一次。
  • 除以含 y 的式子時，要檢查它等於 0 的情況。
  • 通解有 C，特解是用初始條件把 C 定下來。

容易錯的地方

  • 積分 dy/y 時，忘了 ln 裡要加絕對值。
  • 兩邊各加一個常數。這不算錯，但是多餘，合併成一個就好。
  • 解完不驗算，符號錯了也不知道。
