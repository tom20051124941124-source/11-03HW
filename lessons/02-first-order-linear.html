微分方程筆記

02 一階線性方程

不能分離變數的線性方程，乘上積分因子後，左邊會變成一個乘積的導數。

這頁要會什麼

  • 把方程整理成標準形
  • 算出積分因子
  • 解出通解，並說明它由哪兩部分組成
  • 代回原方程驗算

觀念

標準形是 y' + P y = Q，其中 P 和 Q 都只含 x。

積分因子 μ = e∫P dx。兩邊乘上 μ 之後，左邊正好是 μy 對 x 的導數。

解題步驟

  1. 整理成 y' + P y = Q。y' 前面的係數一定要是 1，不是 1 就先全部除掉。
  2. 算 μ = e∫P dx。這裡的積分不用加常數。
  3. 兩邊乘上 μ，左邊變成 μy 的導數。
  4. 兩邊積分，得到 μy = ∫ μQ dx + C。
  5. 兩邊除以 μ，解出 y。
  6. 代回原方程驗算。

例題

例一 y' + 2xy = x

已經是標準形，P = 2x，Q = x。

μ = e∫2x dx = ex² ex² y' + 2x ex² y = x ex² 左邊就是 ex²y 的導數 ex² y = ∫ x ex² dx = ½ ex² + C y = ½ + C e−x²

驗算：y' = −2xC e−x²，2xy = x + 2xC e−x²。兩式相加，含 C 的項互相抵消，剩下 x，等於原方程右邊。

通解的組成

上一頁解過 y' = 2xy。這一頁的方程把右邊換成 x 之後，通解長這樣：

部分內容來源
齊次解C e−x²令右邊 Q = 0 解出來
特解½讓原方程成立的一個解
通解½ + C e−x²兩者相加

這個結構之後在二階非齊次方程還會再出現。

考點

  • y' 的係數一定先化成 1，才能讀出 P 和 Q。
  • 積分因子不加常數，常數留到最後一次積分才加。
  • 通解等於齊次解加特解。

容易錯的地方

  • 遇到 x y' + y = x² 這種題，沒有先除以 x，P 和 Q 就讀錯了。
  • 指數的正負號寫反，例如把 e−x² 寫成 ex²。
  • 最後除以 μ 時，漏了把 C 一起除，結果 C 前面沒有指數項。
